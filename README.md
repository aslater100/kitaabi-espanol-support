# Kitaabi Español support site

The public support page and privacy policy for **Kitaabi Español** ("Kitaabi: Spanish Learning" on the App Store), served at https://es.kitaabi.co by GitHub Pages from `main`.

| File | Page |
|---|---|
| `index.html` | Support page (the App Store support URL) |
| `privacy.html` | Privacy policy (the App Store privacy URL) |
| `style.css` | Shared styles, copied from the Arabic support site |
| `CNAME` | Custom domain for GitHub Pages. Don't delete it. |

## What belongs here

Only public pages for the Spanish app. The Arabic app (Kitaabi) has its own support site in [`aslater100/kitaabi`](https://github.com/aslater100/kitaabi). The app's code lives in the private repo `aslater100/kitaabi-espanol`.

## Updating

1. Edit the page and keep it in plain US English.
2. When the app starts collecting new data, update `privacy.html` in the same change as the app's privacy label.
3. Push to `main`, then reload https://es.kitaabi.co after about a minute to check the change.

This repo is not connected to Vercel. kitaabi.co itself serves the web app and is deployed only by hand from the Arabic app repo.
